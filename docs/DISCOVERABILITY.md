## Search and sharing

The README explains the video-to-character workflow, supported formats, quick start, tested behavior, limitations, and contribution paths in normal language. The application HTML includes a descriptive title, meta description, author, and Open Graph/social summary metadata. The public GitHub repository is the discoverable project page for this source release; there is no hosted application yet. GitHub controls the repository page's HTML metadata, so changing `index.html` alone does not change GitHub search snippets.

After a separately authorized website deployment, set canonical and sharing URLs to that actual deployment, verify public crawling, and register it with the chosen search console if needed. Do not point an application canonical URL at a different source-code page or claim a live demo before it exists.

Helpful descriptions and relevant topics support discovery; search engines choose their own snippets and ranking. Do not repeat keywords, fabricate ratings, or promise search placement.

References: [Google title guidance](https://developers.google.com/search/docs/appearance/title-link), [Google snippet guidance](https://developers.google.com/search/docs/appearance/snippet), and [GitHub topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics).
